# 💊 Pharm-DDI Expert Suite (약학 약물 상호작용 & 클리닉 입지별 임상 가이드 시스템)

본 시스템은 약사가 환자의 복용 약물 간의 **병용 금기(Contraindicated)**, **중대한 위험(Major Warning)**, **병용 주의(Moderate Caution)** 상호작용 및 기전, 예상 부작용, 약학적 중재 방안을 즉각 확인하고, **약국 인근 병원/클리닉 진료과목별 주요 처방 충돌 위험**을 상시 모니터링하며, **약봉투 OCR 자체 분석**, **다중 약사 협업 임상 메모 및 상담일지**를 로컬에 안전하게 보존할 수 있도록 구축된 **온프라미스(On-Premise) 모바일 반응형 웹 서비스**입니다.

---

## 📊 시스템 데이터베이스 규모

- **탑재 의약품 DB**: **516종** (국내 원외처방 및 다빈도 13개 카테고리 전수 망라)
- **약물 상호작용(DDI) 규칙**: **766건** (식약처 DUR 고시 및 임상 가이드라인 반영)
- **최신 2개년(2024~2025) SCI 학술 경보**: JAMA, JACC, Circulation 등 권위지 최신 규명 임상 경보 탑재
- **병원 입지별 임상 가이드**: 5개 주요 진료과 (3단계 계층: 고위험 / 경고 / 주의)
- **로컬 데이터베이스**: SQLite 영구 보존 (`pharmacy.db`)

---

## 🌟 주요 핵심 기능

### 1. ⚡ 약물 교차 반응 & 상호작용 정밀 분석기 (Interactive DDI Checker)
- **516종 의약품 선택 및 검색**: 카테고리별 필터 및 실시간 성분명/상품명 자동완성 검색.
- **심각도별 정밀 분석**:
  - 🚨 **병용 금기 (Contraindicated, 219건)**: 식약처 DUR 공식 고시 및 치명적 약물 조합.
  - ⚠️ **중대한 위험 (Major Warning, 503건)**: 장기 손상, 출혈, 약효 급감 및 대사효소 저해 위험.
  - ℹ️ **병용 주의 (Moderate Caution, 44건)**: 모니터링 및 복용 시간차 분리 권고.
- **최근 2개년 SCI 최신 정보 뱃지**: 2024~2025년 발표된 최신 연구 가설이 포함된 경우 상단 및 카드에 '최신 정보' 뱃지 자동 표기.

### 2. 🏥 병원 입지별 3단계 처방 감시 가이드 (Clinic Proximity Guard)
- **정형외과 / 신경외과 / 통증의학과**: NSAIDs 대량 처방과 항응고제 출혈, Triple Whammy 신부전.
- **정신건강의학과 / 신경과**: SSRI 세로토닌 증후군, QT 연장, 중추신경 억제제 중복.
- **이비인후과 / 소아청소년과 / 호흡기내과**: 마크로라이드계 항생제와 스타틴/CCB 대사 차단, 1세대 항히스타민 졸음.
- **비뇨의학과 / 피부과 / 산부인과**: PDE5 억제제와 질산염제제 저혈압 쇼크, 레티노이드 가임기 금기.
- **치과 / 안과 / 일반내과**: 항혈전제 복용자 발치 지혈 관리, 비스포스포네이트 턱뼈괴사(MRONJ), 녹내장 항콜린 금기.
- **3단계 계층 구분**: 각 진료과별로 `고위험(붉은색)`, `경고(주황색)`, `주의(푸른색)` 조합을 체계적으로 구조화.

### 3. 📸 약봉투 OCR 자동 분석 & 방문 환자 관리
- **약봉투 사진 업로드 OCR 분석**: 환자가 가져온 약봉투 사진을 웹 브라우저에서 Tesseract.js 엔진으로 자체 OCR 분석.
- **약물명 자동 매칭 & 원클릭 전송**: OCR 추출 텍스트에서 516종 마스터 DB를 교차 분석하여 발견된 약물을 즉시 DDI 검사기로 전송.
- **방문 환자 차트 관리**: 기저질환, 알레르기, 정기 복용약 및 방문 일지 관리.

### 4. 📝 다중 약사 협업 임상 메모 & 실시간 플로팅 알림
- **파트타임 약사 협업**: 기록자 표시 및 다른 약사들의 추가 코멘트/답글 스레드 지원.
- **새로운 기록지 실시간 플로팅 알림**: 다른 약사가 신규 환자 상담일지나 임상 메모를 등록하면 화면 우측에 실시간 플로팅 알림 배너 자동 표기.

## 🚀 온프라미스 실행 방법

### 요구사항
- Python 3.10 이상 (추가 외부 종속성 없이 표준 라이브러리로 무설치 가동)

### 실행
```bash
# Windows 바로가기
start_server.bat 실행

# 터미널 직접 실행
python server.py
```
브라우저에서 `http://localhost:8085` 로 접속합니다.
